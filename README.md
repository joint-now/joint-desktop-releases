# Joint Desktop Production Releases

Official public production installers and automatic update metadata for the Joint desktop app.

## Contents

- GitHub Releases contain Joint Inc. signed Windows installers and signed and notarized macOS installers.
- `docs/electron` contains the production update feed and download manifest generated by the release workflow.
- Each release records the source commit and workflow run used to build its artifacts.

Release artifacts and update metadata are published only by the Joint Desktop production release workflow.
